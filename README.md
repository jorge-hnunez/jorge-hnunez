## 🚀 Kidemma — Mobile Training Incubator

<img width="2400" height="680" alt="kidemma-banner" src="https://github.com/user-attachments/assets/8bc900c4-23a1-4945-a41c-5ecf3988a62e" />

**Kidemma** is a training initiative I founded within Accenture's Mobility capability — a space where developers strengthen real skills by contributing to an actual mobile application, instead of isolated tutorials.

**Where it came from:** It started as a personal need — a way to actually apply what I was learning from courses and self-study, instead of letting that knowledge stay theoretical. Other developers had the same itch, and what began as a personal project grew into a shared initiative for the whole capability.

**Important — this was never about shipping to an app store.** Kidemma's goal isn't publishing the app to Google Play or the App Store; it's simulating a real professional development environment — planning, pull requests, code reviews, and cross-team collaboration — so participants build the muscle memory of how software actually gets built, not just how to code in isolation.

**How it works:**
- 11 developers collaborating across Android, iOS, and React Native on a real, production-style app
- Weekly 15-minute sync per platform track, plus biweekly demos across the whole group
- Real-world practices: pull requests, code reviews, architecture discussions, modern tooling (Jetpack Compose, SwiftUI)
- Fully voluntary, designed to never compete with anyone's client-project commitments

**My role:** Founder and Product Owner — wrote the original concept and user stories — and Android technical lead, running architecture workshops and mentoring the Android track (5 developers, high rotation).
